# Bundled source and browser libraries

## FF_app and FOCUS

`FF_app/` contains the executable FF engine, original Flask dashboards, original tests, benchmark definitions, documentation and sample generator from `JaredVogler2/FABLE_FOCUS_REVIEW` commit `61d6776ada470980e837d761ef24a3508496d757`. The owner requested its inclusion directly in ASTRA-FOCUS-1. Other reference revisions are recorded in `sources.lock.json`; no runtime access to those repositories is needed.

Scheduling/domain code and original tests match the referenced source bytes. The two mini fixture archives were regenerated by the original deterministic generator/gates. Unrelated generated outputs, Git history, the large dashboard booklet and an unused animated background are not required to run the application and are omitted.

Local dashboard adaptations load the browser libraries below from the same server, update the missing-library help text to the local path, and use the included PNG for the standalone landing-page background. All original source headers and `FF_app/web_flask/VENDOR_CHANGES.md` are retained. Root deployment instructions supersede historical hosting instructions in the inherited documents.

## Browser libraries

| Library | Bundled version | License file |
|---|---|---|
| vis-timeline / vis-graph2d | 7.4.8 | `vis-timeline-LICENSE.md`, `vis-timeline-LICENSE.MIT.txt`, `vis-timeline-LICENSE.Apache-2.0.txt` |
| Chart.js | 4.4.0 | `chart.js-LICENSE.md` |
| SheetJS CE | 0.18.5 | `SheetJS-LICENSE` |

These are the versions used by the reference dashboard, now served from `FF_app/web_flask/static/`. Their source URLs and SHA-256 checksums are recorded in `assets.lock.json`. No browser CDN request is required. The Chart.js filename is `chart.umd.js`; it is the distributed UMD build. The original license headers are preserved in the bundled files.

Python framework packages, including Flask, are installed from the pinned root `requirements.txt`; they retain their upstream licenses in the installed distributions. An already-built container needs no package download to start.
